# 🧙‍♂️ Астро Гном v2.0

> Улучшенная версия Telegram Mini App для гороскопов с современной архитектурой

## 🚀 Как запустить проект

### Требования
- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/benjiros23/gnome-horoscope-v2.git
cd gnome-horoscope-v2

# Устанавливаем зависимости
npm install

# Запускаем в режиме разработки
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

### Команды для разработки

```bash
# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр продакшен сборки
npm run preview

# Запуск тестов
npm run test

# Запуск тестов с UI
npm run test:ui

# Линтинг кода
npm run lint

# Автоматическое исправление lint ошибок
npm run lint:fix

# Форматирование кода
npm run format

# Проверка типов TypeScript
npm run type-check
```

## 📱 Тестирование в Telegram

### Локальное тестирование
1. Запустите проект: `npm run dev`
2. Используйте ngrok для создания HTTPS туннеля:
   ```bash
   # Установите ngrok
   npm install -g ngrok
   
   # Создайте туннель
   ngrok http 3000
   ```
3. Скопируйте HTTPS URL из ngrok
4. Создайте бота в [@BotFather](https://t.me/BotFather)
5. Настройте Web App через команду `/newapp`

### Деплой на Vercel
1. Подключите репозиторий к Vercel
2. Vercel автоматически деплоит из main ветки
3. Используйте production URL для настройки Telegram Mini App
